## 明确的验证限制

- 内置浏览器 URL 安全策略禁止 `file://`，因此没有直接实测双击本地 HTML。产物采用经典内联脚本、内联 CSS，无模块或网络依赖，已通过同一 HTML 的 HTTP 加载和断网操作验证。
- 未进行 Safari、Firefox、真实 iOS / Android 设备兼容性测试。
- 未对 40 张大图、160 百万总像素等最大负载做压力测试；数值为应用限制，不是对所有设备的内存保证。
- HEIC / HEIF 以合成编码样本验证，未声称覆盖所有手机厂商、HDR 色彩或所有特殊编码变体；SVG 的外部资源和交互脚本有意不支持。
- APNG 使用单帧带动画标记样本；尚未用多帧动态 WebP / AVIF 验证首帧选择。产品本身只导出静态图。
- PDF、PSD、相机 RAW 和特殊 TIFF 不属于当前支持范围。
- 没有发布线上站点，没有创建远程仓库或推送代码。
